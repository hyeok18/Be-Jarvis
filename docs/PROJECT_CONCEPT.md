# 맛집 리뷰 신뢰도 지도: 초기 아이디어

> 이 문서는 인터뷰 전 아이디어 기록입니다. 최종 구현 범위와 수용 기준은 루트의 [`PRD.md`](../PRD.md)를 따릅니다.

## 문제

맛집 리뷰 시장에서는 업체가 금전, 음식, 할인, 서비스 등을 제공하고 긍정적인 리뷰를 유도할 수 있다. 사용자는 단순 평균 별점만 보고 실제 방문자의 만족도와 홍보성 평가를 구분하기 어렵다.

## 제품 가설

일반 소비자가 지도에서 식당을 검색하고 다음 정보를 비교하면 광고성 리뷰에 덜 휘둘리는 선택을 할 수 있다.

- 전체 원본 평점
- 리뷰 신뢰도를 반영한 보정 평점
- 방문 인증 리뷰의 평점
- 이상 패턴이 감지된 리뷰의 수와 평균
- 평점이 조정된 구체적인 이유

## 별점 초안

| 점수 | 의미 |
|---:|---|
| 0점 | 먹기 힘들고 다시 방문하지 않을 맛 |
| 1점 | 기대 이하이며 추천하기 어려운 맛 |
| 2점 | 무난하지만 일부러 찾아갈 정도는 아닌 맛 |
| 3점 | 맛있고 주변에 추천할 수 있는 맛 |
| 4점 | 이 메뉴를 먹기 위해 방문할 가치가 있는 맛 |
| 5점 | 특별한 경험으로 오래 기억될 맛 |

## 분석 원칙

- 특정 기간의 고평점 급증을 이상 신호로 탐지한다.
- 여러 리뷰 사이의 문장 유사도와 반복 표현을 분석한다.
- 리뷰어의 평점 분포와 활동 패턴을 신뢰도 계산에 참고한다.
- 하나의 신호만으로 리뷰를 조작으로 확정하지 않는다.
- 자동 삭제보다 라벨 표시와 가중치 조정을 우선한다.
- 원본 평점, 보정 평점, 조정 근거를 사용자에게 함께 공개한다.

## 초기 데이터 원칙

- 리뷰가 적은 식당에는 `평점 형성 중` 상태를 표시한다.
- 리뷰 수가 적을수록 개별 리뷰의 영향력을 제한한다.
- 원본 리뷰와 계산 결과를 분리해 알고리즘 변경 시 재계산할 수 있게 한다.
- 의심 데이터는 삭제하지 않고 격리 상태로 보존한다.
- 리뷰어 신뢰도와 식당 평점이 서로 순환하여 강화되지 않도록 계산 근거를 분리한다.

## 24시간 MVP 후보

1. 지도 기반 식당 탐색
2. 식당별 원본 평점과 보정 평점 비교
3. 리뷰어별 평점 분포 계산
4. 기간별 고평점 급증 탐지
5. 리뷰 문장 유사도 탐지
6. 이상 패턴 라벨과 조정 사유 표시

최종 기능 범위, 데이터 출처, 기술 구성 및 수용 기준은 심층 인터뷰가 끝난 뒤 `PRD.md`에 확정한다.
