# 제품 비전과 개인화 로드맵

이 문서는 팀 인터뷰에서 합의한 장기 방향과 24시간 MVP의 경계를 설명한다. 현재 구현 계약과 수용 기준은 루트의 [`PRD.md`](../PRD.md)가 우선한다.

## 1. 제품 비전

사용자는 단순 평균 별점이 아니라 다음 두 질문에 각각 답을 얻어야 한다.

1. 이 식당은 전체 이용자 관점에서 얼마나 만족스럽고 리뷰 근거가 신뢰할 만한가?
2. 이 식당은 내 취향·제외 음식·과거 만족도에 얼마나 잘 맞는가?

이를 위해 공개 점수와 개인화 점수를 같은 숫자로 섞지 않고 서로 다른 근거와 순위로 제공한다.

## 2. 팀 인터뷰 확정 결정

| 영역 | 결정 |
|---|---|
| 리뷰 별점 | 맛·청결·서비스를 각각 입력하고 맛을 가장 크게 반영한다. |
| 공개 평점 | 리뷰어 개인 가중치를 제거하고 리뷰별 좋아요·싫어요 반응만 완만한 가중치로 사용한다. |
| 공개 신뢰도 | 리뷰 자체·식당 단위 규칙과 AI 분석, 커뮤니티 반응을 사용하되 리뷰어 활동·평점 분포, 개인 취향이나 리뷰어 유사도를 사용하지 않는다. |
| 나와의 매칭도 | 취향 입력, 안 먹는 음식, 밸런스 게임, 이전 방문 만족도, 유사 리뷰어 신호를 사용한다. |
| 개인화 신뢰도 | 리뷰어 유사도 가중치를 사용할 수 있지만 해당 사용자 결과에만 적용한다. |
| 화면 | 기본 종합순위와 나와의 매칭순위를 탭으로 전환하고 카드에 매칭도와 근거를 함께 보여준다. |

## 3. 단계별 우선순위

### P0 — 24시간 MVP

- 맛 60%, 청결 20%, 서비스 20%의 버전 있는 다면 별점
- 합성 좋아요·싫어요 집계와 상·하한이 있는 커뮤니티 가중치
- 공개 점수에서 리뷰어 개인 가중치 완전 제거
- 로그인 없는 브라우저 로컬 선호 프로필
- 안 먹는 음식 hard exclusion, 짧은 밸런스 게임, 직접 취향 입력
- 합성 방문 만족도·리뷰어 유사도 fixture를 이용한 매칭 엔진 검증
- 종합순위·나와의 매칭순위 탭과 설명 가능한 매칭 근거

P0에서는 실제 사용자의 선호·방문·투표를 서버에 저장하지 않는다. 시연 데이터는 모두 합성 fixture다.

### P1 — 계정 기반 개인화

- 일반 사용자 Supabase Auth
- 선호 프로필과 방문 만족도의 기기 간 동기화
- 실제 리뷰 좋아요·싫어요와 계정별 리뷰당 1표
- 자기 리뷰 투표 차단, rate limit, 감사 로그와 집계 재생성
- 사용자별 개인화 결과 캐시와 전체 삭제·내보내기
- 실제 이용 후 만족도 기반 추천 품질 평가

P1은 P0 수용 기준과 발표 흐름이 완료된 뒤 별도 작업 단위로 등록한다.

### P2 — 학습형 추천과 지역 확장

- 충분한 공통 평가가 쌓인 뒤 협업 필터링 고도화
- 선호 신호별 설명 품질과 가중치 실험
- 시간대·동행·예산·거리 문맥 추천
- 성수동 외 지역 확장
- 어뷰징 탐지와 커뮤니티 반응 품질 모델

## 4. 추천 알고리즘 원칙

- hard exclusion을 점수보다 먼저 적용한다.
- cold-start 사용자는 취향 입력만으로 시작하고 없는 이력을 0점으로 취급하지 않는다.
- 유사 리뷰어 신호는 공통 평가 식당이 5개 이상일 때만 사용한다.
- 공개 점수와 개인화 점수는 입력·함수·저장 위치를 분리한다.
- 모든 가중치와 임계값은 버전 설정으로 관리하고 변경 시 fixture를 재계산한다.
- 매칭 숫자만 노출하지 않고 실제 사용된 근거 1~3개를 함께 보여준다.

## 5. 데이터·안전 원칙

- P0 개인화 데이터는 브라우저 로컬에만 저장하며 초기화 기능을 제공한다.
- P1 사용자 소유 데이터는 `user_id` 기반 RLS와 최소 권한을 적용한다.
- 공개 집계는 개인 선호·방문 이력·리뷰어 유사도 테이블을 조인하지 않는다.
- 실제 투표는 인증·중복 방지·자기 투표 차단 없이 공개 점수에 반영하지 않는다.
- 사용자 취향을 광고 타게팅이나 공개 프로필로 전환하지 않는다.

## 6. 단계별 성공 지표

| 단계 | 지표 |
|---|---|
| P0 | 공개 공식과 개인화 공식 테스트 통과, 제외 음식 100% 차단, 매칭 근거 표시, 발표 3회 성공 |
| P1 | 취향 설정 완료율, 매칭순위 전환율, 추천 방문 후 만족도, 투표 중복·권한 오류 0건 |
| P2 | 공개순위 대비 매칭순위의 만족도 개선, 추천 다양성, 설명 이해도, 어뷰징 대응 시간 |
