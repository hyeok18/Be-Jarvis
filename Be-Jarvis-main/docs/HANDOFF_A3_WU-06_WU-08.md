## 인계 범위

### WU-06 — 공개 지도 셸과 mock 반응·매칭 UI

구현과 자동 품질 검증은 완료됐다. 남은 작업은 브라우저 수동 검증과 완료 처리뿐이다.

- 완료된 검증: `pnpm test` (16개 테스트), `pnpm run lint`, `pnpm run typecheck`, `pnpm run build`
- 남은 검증: 390×844 및 1440×900 viewport에서 아래 항목 확인
  - `지도 탐색`, `나와의 매칭`, `크리에이터 방문` 탭 전환
  - 카드 선택과 mock 지도 핀의 동기화
  - 반응 0건 및 10건 미만 상태 표현
  - 가로 overflow, 잘림, 키보드 포커스 문제
- 완료 처리: 확인 결과를 WU-06 개발일지에 추가하고, `docs/DEVELOPMENT_PRIORITY.md`와 `docs/development-logs/INDEX.md` 상태를 `완료`로 갱신한다.

### WU-08 — 식당 상세·한 탭 반응·개별 영상 근거 UI

WU-06이 완료된 뒤에만 시작한다. WU-08의 선행 조건은 WU-06이다.

- 구현 범위: 식당 상세, 좋아요·그냥 그래요·싫어요 한 탭 반응 UI, 체크인 공개 반영 안내, 확인된 YouTube 영상 근거
- 표시 규칙: 별점·평균·종합점수 금지; `confirmed` 영상만 공개; 구독자 수는 최신 API 원값만 표시; 출처·원본 링크·데이터 기준 시각 표시
- 범위 밖: 실제 Auth·반응 저장은 WU-09, 위치 체크인은 WU-10, Kakao 지도·필터는 WU-07
- 완료 전 확인: 상세 화면의 로딩·빈 결과·오류 상태, 390px/1440px 반응형, 키보드 흐름, 금지된 점수 필드 미노출

## 작업 순서

1. A1이 WU-06 UI 파일을 더 이상 수정하지 않는지 확인한다.
2. WU-06 브라우저 수동 검증을 실시하고 결과를 기존 개발일지에 기록한다.
3. WU-06 완료 상태를 보드와 인덱스에 반영한다.
4. WU-08을 `진행 중`으로 변경하고 새 개발일지를 만든다.
5. WU-08만 구현·검증한다. 같은 시점에 A2의 WU-07과 전역 스타일을 함께 변경해야 하면 팀에 먼저 알린다.
