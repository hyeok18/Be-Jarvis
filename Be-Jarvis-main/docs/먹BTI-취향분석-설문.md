# 쟤가 먹길래 먹BTI 취향 분석 설문

## 설문 목적

사용자의 음식 취향을 간단히 파악해 식당별 `나와의 예상 일치율`을 보여준다.

설문은 정답을 요구하지 않으며, 사용자는 각 질문에서 가장 가까운 답변을 하나 선택한다.

## 공통 선택 규칙

- 한 질문당 답변은 1개만 선택한다.
- 선택한 답변을 다시 누르면 선택이 해제된다.
- 모든 질문에 답해야 `취향 저장하기` 버튼이 활성화된다.
- 저장 전에는 결과를 임시 상태로만 보관한다.
- 저장 후에는 내 정보 화면에서 취향 설정 완료 상태를 보여준다.

## 결과 계산 초안

식당의 음식 태그와 사용자의 선택 태그를 비교해 예상 일치율을 계산한다.

```text
예상 일치율 = 음식 종류 일치 30%
            + 메뉴 스타일 일치 25%
            + 매운맛 유사도 25%
            + 피하고 싶은 음식 충돌 여부 20%
```

- 선호 태그와 식당 태그가 일치하면 점수를 더한다.
- 피하고 싶은 음식과 식당의 핵심 재료가 충돌하면 점수를 크게 낮춘다.
- 취향 설정을 완료하지 않은 사용자는 `취향 설정 후 확인`으로 표시한다.
- 이 점수는 별점이나 종합점수가 아니라 개인 취향 기반 예상치다.

## 화면 문구

- 시작 제목: `내 취향을 알려주세요`
- 설명: `선택한 답변으로 맛집마다 나와의 예상 일치율을 보여드릴게요.`
- 미완료 버튼: `모든 항목을 선택해주세요`
- 완료 버튼: `취향 저장하기`
- 선택 해제 안내: `다시 누르면 선택이 해제돼요.`

## 향후 확장 질문

다음 단계에서 필요할 때 추가한다.

- 가격대: 가성비 / 보통 / 특별한 날
- 식사 분위기: 혼밥 / 데이트 / 모임
- 식감: 바삭한 음식 / 부드러운 음식 / 쫄깃한 음식
- 알레르기 및 반드시 피해야 하는 재료
