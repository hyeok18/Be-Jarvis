## 1. 이번 작업의 목표

- 해결하려는 문제: 기존 계약은 단일 맛 별점과 공개 종합점수만 정의해 팀 인터뷰에서 확정한 다면 별점, 커뮤니티 반응 가중치, 개인화 매칭을 표현할 수 없다.
- 세션 범위: PRD와 로드맵을 정합화하고, 공개 점수와 개인화 점수를 분리한 TypeScript 타입·버전 설정·결정적 fixture·계약 테스트를 구현한다.
- 완료 조건: 인터뷰 결정이 재현 가능한 공식과 타입으로 존재하고 `check:env`, `lint`, `typecheck`, `test`, `build`가 모두 성공해야 한다.
- 범위 밖 항목: Supabase migration, 실제 사용자 Auth·투표 저장, 개인화 UI, Production 배포.

## 2. 무엇을 만들었는가

- 맛 60%, 청결 20%, 서비스 20%의 리뷰 종합별점 계약을 만들었다.
- 좋아요·싫어요에 사전 강도 10과 `0.75~1.25` 상·하한을 적용한 커뮤니티 가중치를 구현했다.
- 다면 점수, 공개 평점, 공개 리뷰 신뢰도, 종합점수의 커뮤니티 가중평균 함수를 구현했다.
- 공개 계산 입력 타입에서 사용자 취향·리뷰어 유사도를 제거하고 리뷰어 키를 바꿔도 결과가 같은 계약 테스트를 만들었다.
- 리뷰어 평점 분포 신호 `REVIEWER_ONE_SIDED`의 공개 감점을 0으로 고정하고 개인화 전용 신호로 분리했다.
- 안 먹는 음식 hard exclusion, 취향 적합도, 최소 공통 평가 5개의 유사 리뷰어, 방문 만족도, 신호 재정규화를 포함한 매칭 함수를 구현했다.
- 개인화 신뢰도와 `매칭도 60% + 개인화 품질 40%`의 개인화 랭킹 점수를 구현했다.
- 식당·다면 원본 리뷰·반응 집계·분석 실행·리뷰 분석·식당 점수·로컬 선호·매칭 근거 타입과 합성 fixture를 만들었다.
- 24시간 P0와 계정 기반 P1, 학습형 P2의 경계를 `VISION_ROADMAP.md`에 문서화했다.

## 3. 무엇이 문제였고 어디에서 막혔는가

- 기존 24시간 MVP는 일반 사용자 계정·리뷰 작성·개인 맞춤 추천을 제외하고 있어 인터뷰의 전체 비전을 그대로 한 번에 넣으면 P0 완료를 지연시킬 위험이 있었다.
- 개인별 취향·방문 만족도·리뷰 투표는 개인정보와 남용 방지 규칙이 필요하므로 공개 랭킹 데이터와 같은 경계로 저장할 수 없었다.
- 기존 `REVIEWER_ONE_SIDED` 감점은 공개 신뢰도를 통해 사실상 사람별 가중치로 작동할 수 있어 “전체 평점에서 사람 가중치 제거” 결정과 충돌했다.
- 첫 최종 테스트에서 개인화 랭킹 기대값을 79.61로 적었지만 저장된 공개 평점 4.18을 사용한 실제 둘째 자리 반올림 결과는 79.62여서 1개 테스트가 실패했다.

## 4. 어떻게 해결했는가

- P0는 익명 로컬 선호와 합성 반응·방문·리뷰어 fixture를 사용하고, 실제 계정·투표·동기화는 P1로 분리했다.
- 공개 함수와 개인화 함수의 입력 타입을 분리해 공개 경로가 리뷰어 유사도나 사용자 취향을 받을 수 없게 했다.
- `REVIEWER_ONE_SIDED`의 공개 penalty를 0으로 고정하고 설정 검증 테스트를 추가했다. 공개 GPT 후보 판정에서도 이 신호를 제외하도록 PRD를 수정했다.
- 실제 투표의 후속 조건으로 인증, 리뷰당 1표, 자기 리뷰 투표 차단, rate limit, 감사 로그를 기록했다.
- 반올림 실패는 구현을 바꾸지 않고 “식당 공개 평점을 둘째 자리로 저장한 뒤 개인화 품질에 사용한다”는 계약에 맞춰 기대값을 79.62로 바로잡았다.

## 7. 남은 위험과 미해결 항목

- 다면 별점과 반응 집계는 아직 Supabase migration으로 검증되지 않았다.
- 매칭 공식은 실제 사용자 데이터가 없어 합성 fixture로만 검증했다. 실제 가중치 조정은 P1에서 만족도 지표를 수집한 뒤 버전을 올려야 한다.
- 실제 좋아요·싫어요는 계정별 1표, 자기 리뷰 투표 차단, rate limit과 감사 로그가 구현되기 전에는 공개 점수에 연결하면 안 된다.
- 브라우저 로컬 선호의 schema versioning·초기화 UI는 WU-06에서 구현해야 한다.
- 현재 작업 단위 내부 미해결 항목: 없음.
