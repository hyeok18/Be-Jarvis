# 비자비스 개발일지 인덱스

새 세션은 이 표에서 `진행 중` 또는 `막힘`을 먼저 찾고, 없다면 `다음 작업`을 시작한다. 각 작업 단위의 상세 상태는 연결된 개발일지를 기준으로 한다.

| 작업 단위 | 제목 | 상태 | 최신 기록 | 개발일지 | 다음 작업 또는 재개 지점 |
|---|---|---|---|---|---|
| WU-00 | 프로젝트 운영 규칙과 개발일지 체계 | 완료 | 2026-08-24 | [기록](./2026-08-24_WU-00_project-governance.md) | WU-01 공식 기준 확인부터 시작 |

## 상태 갱신 규칙

- 새 작업을 시작하면 해당 행을 추가하고 `진행 중`으로 표시한다.
- 외부 입력 없이는 진행할 수 없으면 `막힘`과 정확한 재개 조건을 적는다.
- 구현·테스트·문서화가 끝나면 `완료`로 바꾸고 다음 작업 단위를 적는다.
- 최신 기록이 위로 오도록 할 필요는 없으며 작업 단위 ID 순서를 유지한다.
- 개발일지 파일을 삭제하거나 이전 실패 기록을 지우지 않는다.
