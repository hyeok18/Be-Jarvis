# 맛집 리뷰 신뢰도 지도

광고성·협찬성 리뷰가 맛집 평점을 왜곡하는 문제를 줄이기 위한 24시간 해커톤 프로젝트입니다.

이 서비스는 리뷰를 무조건 삭제하거나 조작 여부를 단정하지 않습니다. 방문 근거, 작성 패턴, 리뷰어 활동 이력 등을 바탕으로 리뷰의 영향력을 조정하고, 원본 평점과 보정 평점 및 계산 근거를 함께 보여주는 것을 목표로 합니다.

## 현재 상태

- 요구사항 심층 인터뷰 진행 중
- 24시간 MVP 범위 확정 예정
- 인터뷰 완료 후 루트에 `PRD.md` 작성 예정

초기 아이디어는 [docs/PROJECT_CONCEPT.md](docs/PROJECT_CONCEPT.md)에서 확인할 수 있습니다.
